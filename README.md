# MediaDoor

MediaDoor is a powerful, lightweight, and visually striking video downloading utility built with Python and PyQt6. Designed with a custom dark-themed UI, it simplifies the process of fetching high-quality media directly to your desktop.

## ✨ Features
* **High-Resolution Video:** Automatically detects and downloads the best available quality, scaling all the way up to 4K.
* **Audio Extraction:** Pull high-quality audio directly from video links in formats including MP3, WAV, and Lossless FLAC.
* **Seamless Updates:** Built-in auto-updater ensures you are always running the latest version without needing to hunt for download links.
* **Clean UI:** A completely custom, animated interface featuring drop shadows, smooth transitions, and dynamic font rendering.

## ⚙️ Core Dependencies & Note on Downloading
MediaDoor relies on the robust **`yt-dlp`** library under the hood to handle video parsing and downloading. 
* *Note on Download Failures:* Because media platforms frequently update their internal architectures, any sudden issues, errors, or interruptions related to fetching or downloading videos are frequently tied to upstream changes in `yt-dlp` or platform-side restrictions rather than the MediaDoor application itself.

## 📥 Installation
1. Navigate to the [Releases](https://github.com/Parasite-exe/MediaDoortest/releases) tab.
2. Download the latest `MediaDoor_v1.1_setup.exe`.
3. Run the installer and launch the app from your Start Menu.
